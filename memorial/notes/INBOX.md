Drop anything here, anytime — a memory, a fact, a date, a photo reference, a
relative's name, a story. No formatting required. When there's a batch worth
adding, ask Claude to "incorporate the notes" and it will fold them into
`index.html` and clear this file (or archive it — see below).

it down.

## How this gets used

1. Add notes below the `## Unsorted notes` heading whenever something comes
   to mind — no need to organize or edit this page yourself.
2. When ready, ask Claude (in this repo) to "incorporate the notes into the
   memorial page."
3. Claude will edit `index.html` (adding/expanding sections like Early Life,
   Career, Personal Life, Gallery, Relations), commit, and push.
4. Incorporated notes get moved into `notes/ARCHIVE.md` so this inbox stays
   short and this file always reflects only what's still pending.
